### 1.2 字段说明

| 字段 | 说明 |
|------|------|
| 规则码 | 唯一标识，形如 `LINK-001` |
| Milestone | 引入该规则的里程碑 |
| Category | 规则类别 |
| 名称 | 规则短名 |
| 描述 | 规则检测逻辑描述 |
| allow_customer_output | 0=不进入客户正式问题清单；1=进入 |
| 版本 | 规则版本号，全部为 v1.0.0 |
| 状态 | 规则状态，全部为 active |

### 1.3 客户问题边界

`allow_customer_output=0` 的规则为内部观测规则，结果不进入客户正式问题清单，仅用于系统内部统计与运营分析：

- M4 ARCH-001~006（异常归档）
- M4 DUP-001~008（重复检测）
- M4 RECON-001~010（市区双渠道对账）

其余 50 条规则 `allow_customer_output=1`，结果进入客户正式问题清单。
