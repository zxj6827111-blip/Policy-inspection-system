## 一、总体目标

将系统从「受控采集 + 初级规则线索 + Excel 导出 + 单条人工复核」升级为「安全可控、规则可信、证据完整、双渠道对账、支持 PDF/OCR、异常归档、重复识别、政策解读检查、整改复查销号的生产级政策公开巡检平台」。

最终业务覆盖：

1. 异常归档：已更新但依旧归档、不应归档、现行文件异常消失、栏目迁移、正常失效与异常归档区分。
2. 异常文号：页面、正文、PDF 三方比对，文号年份与成文年份比对，主文号、引用文号和被转发文件文号区分。
3. 日期异常：成文日期至首次发布日期超过 20 个工作日、发布日期早于成文日期，以及迁移、补录、勘误等例外。
4. 发文机构与机关代字：公开主体、上传单位、实际发文机关、联合发文机关、转发机关、历史机构和机关代字有效期。
5. 重复数据：同栏目重复、不同 URL 同一政策、同 PDF 不同页面、跨栏目正常重复、跨渠道同步与异常重复。
6. 阅办联动、附件与政策解读：按钮存在、可点击、跳转有效、内容不为空、图片和视频可用、解读与原政策匹配、阅办流程可继续。
7. PDF 与正文规范：损坏、加密、空白、扫描件、OCR、标题/文号/机构/日期三方比对、附件缺失与错挂。
8. 人工复核与整改闭环：批量复核、双人复核、排除原因、整改下发、复查、销号、复发识别和统计分析。

## 十、M4：异常归档、重复与双渠道对账

### 10.1 异常归档

每轮记录：来源、栏目、URL、文档身份、首次发现、最后发现、本轮是否存在、HTTP 状态、页面状态、内容哈希。

判定流程：第一轮缺失只记录 → 第二轮缺失检查原 URL → 搜索迁移 → 判断废止/失效 → 与另一渠道交叉验证 → 形成归档线索 → 人工确认。

规则：`ARCH-001` 现行有效文件连续两轮消失 / `ARCH-002` 页面仍更新但栏目归档 / `ARCH-003` 长期保留栏目异常归档 / `ARCH-004` 市级存在区级长期缺失 / `ARCH-005` 区级存在市级长期缺失 / `ARCH-006` 迁移后原栏目无正确跳转。

### 10.2 重复数据

文档身份指纹：规范化文号、规范化标题、成文日期、发文机构、正文哈希、PDF 哈希、正文相似度、附件组合。

重复类型：技术重复 / 同栏目重复 / 不同 URL 同一文件 / 跨栏目正常重复 / 跨渠道正常同步 / 同 PDF 不同页面 / 文号相同内容不同 / 文号不同内容高度相似。

### 10.3 双渠道对账

匹配结果：市区一致 / 市级缺失 / 区级缺失 / 标题不一致 / 文号不一致 / 日期不一致 / 正文不一致 / 附件不一致 / 更新延迟 / 无法匹配。

### 10.4 门禁

- 单轮缺失不报异常；
- 归档 finding 至少有两轮证据；
- 正常废止、失效、迁移可排除；
- 归档 precision ≥ 95%；
- 同一政策跨渠道匹配 precision ≥ 95%；
- 正常跨渠道同步不判重复；
- 对账差异有双方证据；
- 无法匹配时进入数据不足。

## 十一、M5：阅办联动、政策解读与整改闭环

### 11.1 阅办联动

检查按钮存在、可点击、跳转成功、最终页面有效、不是空白或错误、业务能够进入下一步、不是只返回 200 但显示「暂无数据」。

### 11.2 政策解读

类型：图文解读 / 一图读懂 / 视频解读 / 问答解读 / 负责人解读 / 专家解读 / 新闻发布会 / 媒体解读。

检查：链接有效、图片有效、视频可播放、页面不为空、解读对象与原政策一致、解读发布时间、解读链接是否错挂。

### 11.3 链接状态

正常 / 正常重定向 / 临时网络异常 / 403 / 429 / 验证码 / 页面失效 / 内容为空 / 资源失效 / 关联对象错误 / 待人工复核。

403、429、验证码和临时网络问题不得直接进入确认问题。

### 11.4 整改闭环

流程：人工确认 → 创建整改任务 → 指定责任单位 → 设置整改期限 → 发送整改通知 → 上传反馈 → 自动或人工复查 → 通过 → 销号。不通过则重新下发继续整改。

支持：整改前后证据、状态历史、责任单位、责任人、整改期限、超期提醒、复发问题识别、月/季/年度统计。

### 11.5 门禁

- 正常重定向不误报；
- 403/429 不进入正式问题；
- 视频页面打开但视频失效可识别；
- 200 空页面可识别；
- 解读对象错误可识别；
- 所有正式问题可创建整改任务；
- 整改前后证据完整；
- 状态可追溯；

## 十五、数据库迁移原则

1. 每阶段单独迁移；
2. 迁移前完整备份；
3. 先在生产副本演练；
4. 不直接删除旧字段；
5. 人工复核只追加；
6. finding 带规则版本；
7. 新旧规则可并行；
8. 迁移幂等；
9. 重复执行不得重复插入知识数据；
10. 每次迁移生成前后统计；
11. 生产迁移必须有回滚方案。
